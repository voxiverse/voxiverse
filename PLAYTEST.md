# Flood playtest scorecard

Thresholds (GAME.md §4), written down before the first session.

| Signal | Pass | Session 1 | Session 2 | Session 3 |
|---|---|---|---|---|
| Players start another round unasked | at least 2 of 3 sessions | | | |
| First laugh or shout | within 5 minutes | | | |
| A 20–30 s clip that is funny with no explanation | at least 1 per session | | | |
| Anyone confused for more than 30 s about what to do | nobody after the first round | | | |
| Rounds played in 40 minutes | 4 or more | | | |

## What to watch for, per rule

- **Baseline**: do players climb at all without being pushed, or wait? This is the control: if it is as fun as the others, the hidden rule adds nothing.
- **Tide**: does anyone notice the water falling back and say "it's going down" (or get caught on a ledge that was dry)? Do they guess Tide before the reveal?
- **Rot**: do players notice blocks vanishing near the water and start moving up sooner, or blame each other's rockets?
- **Heavy blast**: does anyone discover the big rocket jump, and does someone blow away a friend's ledge (the clip)? Watch for frustration at being thrown around.
