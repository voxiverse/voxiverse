# M49c: replicating channels (the chunk encodings, the `Channel` record, the client's layers)

**Why.** M49 (split once, 2026-11-01, unattended) built the layers, the scheduler, the flow
behaviour, the saves and `/cell`, and left the one step that touches the wire and the
client: a channel flagged `replicated` is stored and saved on the server but not yet sent.
Everything below is M49's design for it, unchanged; read M49's spec in history.md for the
channels, `Chunk_Layers` and the pools, and this file for what remains.

**Checked against the code (M49's session).** `game.Chunk_Layers`, `Layer_Pools`,
`Saved_Channel` and `write_channel_body`/`read_channel_body` (`common/game/layers.odin`,
`layers_codec.odin`: one body encoding, uniform or palette and runs, shared by saves and
this milestone's chunk encodings), `server/core/channels.odin` (`chunks_channel`,
`set_channel`, `channels_reset_cell`, `Cell_Key`) and `Changes.cells` (a set of
`Cell_Key`, filled by `set_channel` and the reset, not yet read by `changes_flush`) exist.
`hash_chunk_layers(h, layers, defaults, which)` takes the channel set to hash:
`state_hash`'s Chunks section passes every stored channel; `hash_chunks` and
`game.hash_chunk` (the checkpoint, what a mirror can check) must pass the replicated ones
only.

**Design.**

- *Chunk encodings.* `Chunk_Encoding` (`common/game/codec.odin`) gains `Uniform_Layers` and
  `Palette_Runs_Layers`: the blocks exactly as the plain encodings, then `varint n` and n
  channels, each `varint channel id`, then `write_channel_body`'s body. A chunk whose
  replicated channels are all uniform at their defaults uses the plain encoding, so it
  costs not one byte more. `write_chunk(w, blocks, layers, infos)` and `read_chunk`
  replace `write_chunk_blocks`/`read_chunk_blocks` in the chunk message (the old names stay
  as wrappers for the plain case; saves keep their own section). `read_chunk` refuses an
  unknown or computed channel id, a channel listed twice, a value above the channel's
  `max`, palettes over 4096 entries, runs not summing to 4096 and an index past the palette
  (`read_channel_body` already does the last four).
- *The record.* A state kind `Channel` (`Channel_Record {value: u16}`), reliable,
  write-through like `Block`, key type `Cell`: a `Block_Pos` plus the channel id.
  `game.Key` gains `d: i32` (0 for the existing key types; `key_less` compares it last);
  the `Cell` key is encoded as the `Block_Pos` key is, then `varint channel`. The client's
  apply refuses a value above the channel's `max` with `fail(s, "the server sent channel
  <name> value <v> above <max>")`. `changes_flush` puts a `Channel` record for each changed
  cell of a replicated channel (`Changes.cells`) in a chunk the client has and that is not
  being sent whole, after the `Block` records, sorted by (`block_pos_less`, channel).
- *The client* keeps the layers (`world_set_channel`, its own `Layer_Pools` sized from the
  interest area like its block arrays) in `Client_Chunk` and does nothing else with them
  yet; the determinism mirror (`harness_client.odin`) and `net_test`'s clients keep them
  too.
- *The hash.* `hash_chunks`' checkpoint includes replicated channels only.

**Tests.**

- `common/game/protocol_test.odin`: the layered encodings round-trip (uniform, palette,
  several channels, the plain case byte-identical to before); every malformed case above
  fails with the reader failed; `test_chunk_decode_fuzz` covers the new encodings; the
  `Channel` record and `Cell` key round-trip through `test_new_field_needs_no_code`'s
  machinery; the dissector schema regenerated (`build schema`).
- `server/core/layers_test.odin`, `test_channels_replicate` (the test pack of `channel_pack`
  there: `wetness` replicated, `secret` not): `/cell` sets 1 000 cells of `wetness` over
  three chunks and 10 of `secret`; the mirror holds exactly the server's `wetness`, and no
  `secret`; a chunk sent whole after the sets carries them; a block change resets
  `wetness` there on both sides.

**Exit check.** The tests above pass; `server/core/bandwidth_test.odin` passes with the
baseline's roots and no more bytes (chunks without channels cost nothing more);
`build determinism`, `build check` and the whole suite pass; the CI run is green.

**Check by hand.** None.
