# M57: sound design, part one (the synth library, recipes, every effect remade)

Split from the old M57: the library, the recipe format and every existing effect remade
with their tests here; the sounds M58 needs, the listening tools and the reference analysis
in M57b.

- **Decisions.** Effects are synthesized at 48 kHz in float and stay that way: no lo-fi
  stage and no "Retro" option (owner, 2026-10-26: today's crunchy effects do not sound good;
  the goal is effects that sound as good as they can and are pleasant to hear again and
  again). The pixel look stays the world's; the sound does not imitate it. Sounds are generated on a worker thread started first
  thing in `app_init` (before the window opens) and joined in `audio_init` before the
  device opens; the log says `audio sounds generated count=N ms=N waited_ms=N`. Recordings
  are never committed.
- **Room for them**: `audio.MAX_SOUNDS :: 1024` (`Sound_Id` stays u16); `CAPTURE_VERSION ::
  6`.
- **The synth library** (`client/audio/synth/`, package `synth`; replaces `client/sfx`, which
  goes): everything in `f64` internally, `base.sin`/`base.cos`/`base.exp` (ours, the same on
  every OS) and `base.Rng`, so a recipe and seed give the same samples on every OS.
  - `modal.odin`: a bank of up to 16 damped resonators (two-pole, frequency, T60, gain);
    `MATERIAL_MODES :: [Material]Modes` (`Material` here is the same list as M56b's sound
    materials, without Air and Lava): base frequency and six (ratio, T60 s, gain dB) modes:
    stone 1700 Hz `{1, .035, 0} {1.62, .028, -3} {2.33, .022, -5} {3.1, .016, -8} {4.4,
    .012, -11} {5.9, .009, -14}`; wood 420 Hz `{1, .06, 0} {2.1, .045, -4} {3.4, .03, -7}
    {5.2, .02, -10} {7.3, .014, -13} {9.6, .01, -16}`; glass 2600 Hz `{1, .35, 0} {1.42,
    .3, -2} {2.37, .22, -4} {3.51, .16, -6} {4.62, .12, -9} {6.24, .09, -12}`; metal 900 Hz
    `{1, .9, 0} {2.76, .7, -3} {5.40, .5, -6} {8.93, .35, -9} {13.34, .25, -12} {18.64,
    .18, -15}`; dirt 180 Hz `{1, .02, 0} {1.9, .016, -4} {2.8, .012, -8} {4.1, .009, -12}
    {5.5, .007, -15} {7.0, .005, -18}`; gravel 900 Hz T60s .012 down to .004, gains 0 to
    -15; sand 2500 Hz T60s .006 to .002; wool 250 Hz T60s .012 to .004, gains 0 to -20;
    leaves 3200 Hz T60s .004 to .0015; snow 400 Hz T60s .01 to .003; water 600 Hz (bubbles
    instead, below). An exciter (a raised-cosine burst of `length` s, low-passed at `500 +
    15000 * hardness^2` Hz, hardness 1 adding a one-sample click) drives the bank.
  - `granular.odin`: `count` grains, each a short Hann-windowed burst of noise, tone or a
    one-mode resonator, with its own start (uniform in `spread`, or front-weighted
    `density front`), size, pitch and gain drawn from the recipe's ranges.
  - `formant.odin`: a glottal pulse train (Rosenberg pulse) or noise, through three
    band-pass formants that glide between vowel targets (`VOWELS`: a 800/1150/2900, e
    400/1600/2700, i 300/2300/3000, o 450/800/2830, u 325/700/2530, `bleat` 900/2400/3400),
    with a pitch contour, vibrato (rate Hz, depth cents), jitter (random period, 0..1 of 2%)
    and shimmer (random amplitude, 0..1 of 3 dB), `breath` mixing noise.
  - `bubble.odin`: Minnaert bubbles, `freq = 3.26 / r` Hz rising 10% over their decay, for
    water.
  - `layer.odin`: a recipe's layers summed after each layer's envelope, filter, delay and
    level, then the recipe's EQ (low shelf, peaking, high shelf biquads), a 1 ms fade at
    both ends (no click), DC removal (a 10 Hz high-pass).
- **Recipes as data** (`<base pack>/sounds/*.recipe`, the base data pack M47 built, loaded
  and hot-reloaded through its loader in dev builds; the parser is `client/audio/synth/recipe.odin`).
  Grammar (line oriented, `#` comments, indentation free):

  ```
  file     = { sound }
  sound    = "sound" name NL { sound-line } { layer } { eq } "end" NL
  name     = word { "." word }                  ; word = [a-z0-9_]+ ; e.g. stone.break
  sound-line = "class" name                     ; a row of the targets table
             | "variants" int                   ; 1..16, default 8
             | "seed" int                       ; default: FNV-1a of the name
             | "length" number                  ; seconds, the most it may last (0.02..12)
             | "gain" number "dB"
             | "character" ( "clean" | "follow" ) ; default follow (the option)
             | "loop" number                    ; a seamless loop, crossfaded this many s
  layer    = "layer" word NL { layer-line }
  layer-line = "source" source
             | "envelope" "attack" value "hold" value "decay" value [ "curve" ("exp"|"lin") ]
             | "filter" ( "lowpass" | "highpass" | "bandpass" ) value [ "q" value ]
             | "level" value "dB"
             | "delay" value                    ; seconds after the start
             | "pitch" value                    ; a ratio on every frequency in the layer
  source   = "noise" ( "white" | "pink" | "brown" )
           | "tone" value [ "to" value ]        ; Hz, gliding
           | "click" value                      ; hardness 0..1
           | "modal" material { modal-opt }
           | "granular" grain { gran-opt }
           | "formant" { formant-opt }
           | "bubble" "radius" value "count" value "spread" value
  modal-opt = "hardness" value | "modes" int | "spread" value | "decay" value
            | "brightness" value | "length" value
  grain    = "noise" | "tone" | "modal" material
  gran-opt = "count" value | "size" value | "pitch" value | "gain" value "dB"
           | "spread" value | "density" ( "flat" | "front" | "back" )
  formant-opt = "pitch" value [ "to" value ] | "vowel" word [ "to" word ]
              | "vibrato" value value | "jitter" value | "shimmer" value | "breath" value
  eq       = "eq" ( "low_shelf" | "high_shelf" ) value value "dB"
           | "eq" "peak" value value value "dB"        ; Hz, Q, gain
  value    = number | number ".." number            ; a range: drawn per variant
  ```

  A range is drawn once per variant from the variant's generator (`base.rng_make(seed * 64
  + variant)`), in the order the values appear in the recipe, so adding a value later in a
  recipe does not change earlier draws. An unknown word, a parameter out of its range, a
  missing `class` or `end` is an error with file, line and the fix ("stone.recipe:12:
  'hardnes' is not a modal option: hardness, modes, spread, decay, brightness, length").
  Example (`stone.recipe`):

  ```
  sound stone.break
    class block_break
    length 0.5
    layer transient
      source click 0.85..0.95
      envelope attack 0 hold 0 decay 0.010
      filter highpass 1500
      level -6 dB
    layer body
      source modal stone hardness 0.6..0.8 spread 0.94..1.06 length 0.004
      envelope attack 0 hold 0 decay 0.12..0.18 curve exp
      level 0 dB
    layer debris
      source granular modal stone count 8..14 size 0.004..0.012 pitch 0.8..1.6 gain -18..-8 dB spread 0.02..0.30 density front
      envelope attack 0 hold 0.05 decay 0.25
      level -9 dB
    eq peak 3000 1.2 2 dB
  end
  ```
- **Tuning from the console** (dev builds): `sound.tune <name> <layer>.<param> <value>`
  (e.g. `sound.tune stone.break body.hardness 0.7..0.8`) changes the parsed recipe in
  memory, regenerates that sound's variants on the worker and swaps them in with
  `audio.sound_replace(m, id, Sound)`: a command applied by the audio thread at a block's
  start that stops voices of that sound with a 5 ms fade, then swaps; the old samples are
  freed by the game thread after a `Replaced` record on the return ring (the return ring's
  `Voice_Event` gains `kind`). `sound.save <name>` writes the recipe file back.
- **Targets per class** (`<base pack>/sounds/targets.txt`, one row per class, parsed like
  recipes; the numbers are first estimates for M57b's reference analysis to replace):
  measured on each variant at 48 kHz, Clean, gain 1: `peak` (sample peak dBFS), `loud` (the
  highest 400 ms momentary loudness, LUFS, of the sound padded with 400 ms silence),
  `length` (start to the last 5 ms RMS frame above -60 dB re peak), `decay` (the peak to
  -30 dB re peak), `centroid` (Hz, of the whole sound), `low`/`mid`/`high` (energy below
  250 Hz, 250-2500, above 2500, dB relative to the total).

  | class | peak dB | loud LUFS | length s | decay s | centroid Hz | band floors dB |
  |---|---|---|---|---|---|---|
  | block_break | -3..-1 | -24..-14 | 0.15..0.6 | 0.04..0.35 | by material | mid >= -8 |
  | block_place | -4..-1 | -26..-16 | 0.08..0.35 | 0.03..0.2 | by material | mid >= -8 |
  | block_step | -10..-4 | -34..-22 | 0.05..0.25 | 0.02..0.12 | by material | - |
  | land | -6..-2 | -28..-18 | 0.1..0.4 | 0.04..0.2 | 150..1200 | low >= -10 |
  | creature_hurt | -6..-2 | -24..-14 | 0.2..0.7 | 0.08..0.5 | 500..2500 | mid >= -6 |
  | creature_die | -6..-2 | -22..-12 | 0.5..1.5 | 0.2..1.0 | 400..2000 | mid >= -6 |
  | launch | -6..-2 | -24..-14 | 0.3..1.2 | 0.1..0.8 | 1500..6000 | high >= -8 |
  | boom | -1.5..-0.5 | -14..-6 | 1.0..3.0 | 0.3..1.5 | 80..600 | low >= -4 |

  Centroid by material for the block classes: stone 1500..4000, wood 500..1800, dirt
  200..900, gravel 800..3000, sand 1500..5000, glass 2500..7000, wool 300..1500, leaves
  1500..6000, snow 400..1600, metal 600..3000.
- **Rework**: every effect today's `client/sfx` makes, as recipes: break, place and step
  for stone, dirt, grass (now leaves for plants and dirt-and-leaves for grass blocks), sand,
  gravel, glass, wood, snow and wool (split from snow), land, the sheep's hurt and die
  (formant `bleat`), launch, boom (a low thump, a rumble of brown noise, a debris tail).
  Eight variants each. `client/sounds.odin`'s `Sound_Bank` holds `[Sound_Class][]Sound_Id`
  by recipe name; `sounds_play` picks a variant not among the last two played of that
  class (a ring per class) and a pitch within ±3% (`PLAY_PITCH_SPREAD :: 0.03`; variation
  is in the variants now). The baselines (`client/audio_baseline_test.odin`) and
  `effects_spectrum_test.odin` move to the new bank; all are re-accepted (the new
  `baseline_format` drops the other OSes' checksums; CI's log brings them back as in
  M32f).
- **`build sfx`** (`tools/sfx`, linking `client/audio/synth`): writes every variant as
  `build/sounds/<name>.<v>.wav` (24-bit, 48 kHz) and `build/sounds/report.txt`: per sound
  each measure, its target range and `ok` or `OUT` (and exits 1 if any is out).
- **Tests** (`client/audio/synth/synth_test.odin`, `client/sounds_test.odin`):
  - every recipe parses; each malformed case (unknown word, out-of-range value, missing
    `end`, a range with lo > hi) gives its message with the line;
  - every sound: no sample over 1.0 (no clipping); DC under -60 dB
    (mean); first and last 8 samples under -60 dBFS (no clicks); inside its class's
    targets on every measure;
  - variants of a sound differ: any two have third-octave spectra (`audio.third_octaves`)
    at least 1.0 dB apart (RMS over the 24 bands) or decays 10% apart, and none are equal;
  - determinism: two generations are bit-identical; the FNV-1a hashes of `stone.break.0`,
    `glass.place.3` and `boom.0` equal constants held in the test on every OS (the maths
    is ours; if an OS differs, it is a finding: the session keeps that OS on a 1e-6
    tolerance and writes it down);
  - generation of all sounds on the worker in under 1 500 ms at the test build's
    optimization (a guard against runaway cost; the 300 ms release target is logged and
    is a check by hand);
  - `test_sound_tune`: a console tune changes the next generated samples and a voice of the
    old sound playing during the swap ends without a NaN.

Exit check: the tests and CI green; `build sfx` exits 0 with every sound inside its targets.
Check by hand: listen to every class in `build/sounds/` against the old ones (`git stash`
or a checkout of the previous commit: `build sfx` there) and say which to retune; release
build startup's `sounds generated ms=` against the 300 ms target.
