# M58: events (the event table and everything audible)

Split from the old M58: parameterized events and every sound the game makes here; the
ambience in M58b.

- **The event table** (`<base pack>/sounds/events.txt`, hot reloaded in dev builds through
  M47's loader; parsed by `client/sound_events.odin`). Grammar:

  ```
  file   = { event }
  event  = "event" name NL { line } "end" NL
  line   = "sounds" pattern                 ; recipe name, "{param}" replaced by an enum
                                            ;   parameter's value, e.g. {material}.break
         | "bus" ( "world" | "player" | "ui" | "ambience" )
         | "priority" int                   ; 0..255
         | "attenuation" class              ; M56's Attenuation_Class, lower case
         | "pitch" value                    ; a ratio, a range drawn per play
         | "gain" value "dB"
         | "cooldown" number                ; seconds between plays of this event (per emitter
                                            ;   when it has one, else global)
         | "limit" int [ "steal" ( "oldest" | "quietest" | "none" ) ]
         | "no_repeat" int                  ; the last n variants are not picked again
         | "param" word number ".." number  ; a numeric parameter and its range
         | "curve" word ( "gain" | "pitch" | "cutoff" ) point { point }
  point  = number ":" number                ; parameter value : dB, ratio or Hz; linear
                                            ;   between points (cutoff in log frequency)
  ```

  Example:

  ```
  event block_break
    sounds {material}.break
    bus world
    priority 3
    attenuation block
    pitch 0.97..1.03
    gain -1..0 dB
    limit 8 steal oldest
    no_repeat 2
  end
  event land
    sounds player.land
    bus player
    attenuation step
    param speed 5..20
    curve speed gain 5:-12 20:0
    curve speed cutoff 5:2500 20:12000
  end
  ```
- **Events in code**: `Sound_Event_Kind` (an enum, `client/sound_events.odin`) with the
  table's names; `sound_event(app, kind, params: Event_Params)` (`Event_Params :: struct
  {position: Maybe([3]f64), follows: Follow, material: Sound_Material, speed, intensity,
  depth: f32}`) replaces `Sound_Event` and the per-kind switch in `sounds_play`. A play goes
  through `emitter_play` (M56) when it has a position.
- **The events** (each fired from the place named; those marked * exist today):
  `block_break`*, `block_place`* (own predicted edits; other players' from
  `Block_Record.heard`), `step`* (own; other players' from their `Player_Motion` on ground,
  every 1.8 blocks, like `movement_sounds`), `land`*, `creature_hurt`*, `creature_die`*,
  `launch`*, `explosion`*, `player_hurt` (own Health falling), `splash` (feet or chest
  entering water, speed into it as `speed`), `swim` (every 1.2 s while swimming and
  moving), `water_flow` (an emitter on the nearest flowing water block within 12 blocks,
  looped, faded by distance; at most 4), `armor_equip` (an equipment slot filled),
  `item_pickup` (an item entering the inventory from the world), `inventory_click` (a slot
  picked up, put down or swapped), `chest_open`/`chest_close` (the chest record), `door_open`
  /`door_close` (M48's doors changing state), `gate_dial` (each symbol), `gate_open`,
  `ui_click`, `ui_back`, `ui_tab`, `ui_toggle`. (No eating: there is no food yet; when M53
  or a pack adds food, its event is a row in the table.)
- **UI sounds**: `ui.Context` gains `cues: bit_set[Ui_Cue]` (`Ui_Cue :: enum u8 {Click,
  Back, Tab, Toggle}`), set by `button` (Click; a button whose label is Back, Cancel or Done
  sets Back), the tab rows (Tab), choices and checkboxes (Toggle); the client plays the
  frame's cues after `end_frame` (UI has no audio import).
- **Duck 1**: UI -> World, threshold 0.1, amount 0.8, attack 0.005, release 0.2 (menu
  clicks stand out a little).
- **The audio overlay** (`client/audio_overlay.odin`, F3's second page, dev and release):
  the last 32 events (time, name, the sound chosen, gain, refused by cooldown or limit and
  why), live voices by bus with priority, the bus meters and momentary LUFS, the room's
  rt60/open/sky (M56b).
- **Tests** (`client/sound_events_test.odin`):
  - every `Sound_Event_Kind` has a definition; every definition's patterns expand (for each
    enum value used) to recipes that exist, and each of their sounds is non-silent;
  - no-repeat: over 10 000 plays no variant repeats within its `no_repeat` window;
    cooldowns hold to the frame; limits hold, and `steal oldest` stops the oldest;
  - curves: `land` at speeds 5, 12.5 and 20 gives gains -12, -6, 0 dB and the cutoffs
    their log-interpolated values within 1%;
  - a malformed table (an unknown event name, a pattern for a missing recipe, a curve
    with one point) is refused with its line;
  - `test_ui_cues_every_screen`: the UI test walks the title, Singleplayer, Multiplayer,
    Options (every tab), Credits and the game menu, clicks every button and gets the
    expected cue each time.

Exit check: the tests and CI green; `build audio --wav build/audio events` (a new baseline
scenario that fires every event once, 0.5 s apart, at fixed positions) is accepted and
within its numbers. Check by hand: listen to `events.wav`.
