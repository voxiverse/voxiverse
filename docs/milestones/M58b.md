# M58b: ambience (the sound of the world)

- **Sounds made after start**: ambience beds are long, so they are not made before the
  device opens. `audio.reserve_sound(m, rate) -> Sound_Id` (before the device starts) and
  `audio.publish_sound(m, id, Sound)` (a command: the audio thread sets the samples when it
  applies it; a slot goes from empty to full once, so nothing is freed under the audio
  thread); `audio.sound_ready(m, id)` on the game thread. A worker generates the beds after
  the title appears; the ambience waits for a bed that is not ready.
- **Beds** (recipes with `loop 1`, 12 s, made by M57's library at 48 kHz, mono; two
  decorrelated variants each, played as a pair left and right for width): `wind_low`,
  `wind_high` (brown and pink noise through slowly moving band-passes), `birds_day`
  (granular formant chirps), `crickets_night` (pulsed tones 4..5 kHz), `water_near`
  (bubbles and pink noise), `cave_drone` (low filtered noise, 60..120 Hz), `drips` (one-shot,
  not a bed), `leaves_rustle`, `desert_air` (thin high noise), `snow_hush` (very soft
  high-cut noise).
- **The ambience table** (`<base pack>/sounds/ambience.txt`, one row per bed: which
  conditions it plays in and at what gain; parsed like events). Grammar:

  ```
  bed     = "bed" name NL { bed-line } "end" NL
  bed-line = "biomes" word { word } | "biomes" "any"
           | "time" ( "day" | "night" | "dawn" | "dusk" ) { ... } | "time" "any"
           | "height" number ".." number      ; blocks above sea level (the feet)
           | "depth" number ".." number       ; blocks below the column top
           | "near" material number            ; within n blocks of that material
           | "gain" number "dB"
           | "warmth" number ".." number | "wetness" number ".." number   ; Place's
  oneshot = "oneshot" name NL { bed-line } "every" number ".." number "distance" number ".." number "end" NL
  ```

  The base rows: `wind_low` any biome, height -10..60, -24 dB; `wind_high` any, height
  40..256, -18 dB, rising 6 dB from 40 to 120 (a `curve height gain` line, as events);
  `birds_day` plains forest taiga, time day dawn, depth 0..4, -22 dB; `crickets_night`
  plains forest desert, time night dusk, -24 dB, warmth -20..100; `water_near` near water 8,
  -20 dB; `leaves_rustle` forest taiga, -28 dB; `desert_air` desert, -26 dB; `snow_hush`
  tundra frozen_ocean taiga, -30 dB; `cave_drone` depth 12..512, -22 dB; one-shots
  `drips` depth 12..512 every 3..9 s distance 3..10; `distant_bird` plains forest, day,
  every 8..30 s distance 20..40; `creak` forest taiga every 20..60 s distance 6..16.
- **The ambience player** (`client/ambience.odin`): every 0.25 s evaluates each bed's
  conditions against the place (`Place` record, time of day, height, depth from the column
  top, nearby materials sampled from 26 points around the listener at radius 8) to a
  target gain (0 when it does not apply), and moves each bed's voice toward it over
  `AMBIENCE_FADE = 3` s; a bed starts (looped, at gain 0) when its target first goes above
  0 and stops 1 s after it reaches 0. Crossing a biome border therefore crossfades over 3 s
  with no gap and no doubled bed. One-shots are placed at a random direction and distance
  in their range through `emitter_play`. Beds play on Ambience, unpositioned (Speakers
  pan or none).
- **Worlds of other addresses sound different**: the address hash (`game.address_hash`)
  seeds a `World_Voice` per world: each bed's pitch (0.9..1.1), each one-shot's family
  (`distant_bird` takes one of three contour sets), and an extra gain per bed
  (-6..+3 dB), so the same biome sounds unlike itself on another world; `Place.warmth` and
  `wetness` gate the rows that name them. Weather: `bed rain` and `bed thunder` rows are
  accepted with `weather rain|thunder` lines and never match (no weather yet).
- **Tests** (`client/ambience_test.odin`):
  - `test_ambience_golden`: for a table of 24 places (each biome by day and night, a cave
    at depth 20, a mountain top at height 150, beside water) the bed gains equal
    `assets/baselines/audio/ambience.golden` (`build audio --accept ambience` rewrites it);
  - `test_border_crossfade`: walking from plains into desert, the old bed's gain falls and
    the new one's rises over 3 s, their summed power stays within 3 dB of either alone, and
    no bed is ever started twice;
  - `test_other_address`: two addresses give different `World_Voice`s and different bed
    pitches for the same place; the same address twice gives the same;
  - `test_publish_sound`: a voice asked for an unpublished bed waits; published, it plays;
    no NaN and no allocation on the audio thread (the mixer's stats).
  - the tour scenario (`client/tour_check.odin`) logs the bed gains it passes through and
    asserts each biome it visits had its beds above 0.
- **Exit check**: the tests and CI green; a new audio baseline scenario `tour` (the tour
  scenario's path with ambience and steps, 120 s, rendered offline from a recorded list of
  places) is accepted: Ambience's integrated loudness within -30..-20 LUFS, Master's true
  peak under -1 dBTP, `build bench audio` within budget with the beds on. Check by hand:
  listen to `tour.wav`.
